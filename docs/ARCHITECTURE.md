# Architecture

State after CR-2031 / SETCMP (PR #1, branch `devin/SETCMP/cr-2031-settings-compare`). `main` is still the day-zero
AngularJS-only state until a human merges; the previous version of this page described that state.

## Runtime
```
browser ── :3000 frontend/server/dev-server.js (static src/ incl. ng/ bundle + /api proxy) ── :8080 Spring Boot asset service ── H2 (dev/CI) | PostgreSQL 16 (compose)
```

## Backend — `backend/` (Spring Boot 3.3, Java 17) — unchanged by CR-2031
- `web/` — `@RestController`s return DTOs only (ArchUnit-enforced; controllers may not touch repositories or return entities). `ApiExceptionHandler` produces the standard error envelope `{status, error, message, path, timestamp, details[]}`.
- `service/` — transactional use-cases: `SubstationService`, `IedService`, `SettingsService` (upload validation against min/max, version numbering, single ACTIVE), `SclImportService`, `RecordService` (COMTRADE download + audit), `AuditService` (append-only), `Permissions`.
- `scl/` — namespace-aware IEC 61850 SCL parser (`http://www.iec.ch/61850/2003/SCL`), XXE/DTD disabled, 5 MB limit, extension allow-list.
- `domain/` + `repository/` — JPA entities and Spring Data repositories; `@EntityGraph`s avoid N+1 on estate/detail reads.
- `db/migration/` — Flyway `V1__baseline_schema.sql`, `V2__reference_data.sql` (fictional multi-site transmission estate: substations, bays, IEDs, settings history, SCL imports, COMTRADE records, audit history).
- `auth/` — demo identity: `X-SAM-User` header → seeded user → `Role` (PROTECTION_ADMIN, ENGINEER, VIEWER, AUDITOR). Unknown/inactive → anonymous VIEWER.
- `api/openapi.yaml` is generated by `OpenApiExportTest` and committed; `OpenApiContractTest` fails on drift (IC-01). CR-2031 adds no endpoint and does not touch the contract (REQ-SETCMP-022, ADR-004).

## Frontend — `frontend/` (hybrid: AngularJS 1.8.3 + UI-Router 1.1 shell, Angular 16.2 via `@angular/upgrade/static`)

### Bootstrap — ADR-001
- `frontend/src/index.html` carries **no `ng-app`**; `ng-controller="ShellController"` stays on `<body>`. The 4 vendor + 18 AngularJS app scripts load first, then the Angular CLI bundle `ng/runtime.js`, `ng/polyfills.js`, `ng/main.js` as the last three classic `<script>` tags (DES-SETCMP-005 specified `type="module"`; the code uses classic tags placed last, which gives the same execution order — every `angular.module('sam')` block and ui-router state exists before Angular runs).
- `frontend/src/app-ng/main.ts` imports `./downgrades` and then calls `platformBrowserDynamic().bootstrapModule(AppModule)` — the only bootstrap call in the repository. No `angular.bootstrap(...)` anywhere (UM-01).
- `AppModule` (`app.module.ts`) imports `BrowserModule`, `FormsModule`, `UpgradeModule`; has no `bootstrap:` array and no `RouterModule`; `ngDoBootstrap()` runs `this.upgrade.bootstrap(document.documentElement, ['sam'], { strictDi: true })` and then `bridgeLegacyEvents(this.upgrade.$injector, this.events)`.
- zone.js is loaded exactly once through the CLI `polyfills: ["zone.js"]` option in `angular.json`; nothing imports it (ADR-001 §4).
- `strictDi: true` holds because every AngularJS injectable is array-annotated (ESLint `angular/di: array` guards it).

### Routing — ADR-002
- ui-router remains the **only** router; `#!/` URLs, `app.config.js` and `app.routes.js` state names/URLs are unchanged.
- `app.routes.js` `settingsCompare` keeps `url: '/ieds/:id/settings/compare?left&right'` and the dynamic `left`/`right` params but now renders `template: '<sam-settings-compare></sam-settings-compare>'` instead of `templateUrl`/`controller`.
- `app-ng/downgrades.ts` registers `angular.module('sam').directive('samSettingsCompare', downgradeComponent({ component: SettingsCompareComponent }))` on the page-global `angular` before `bootstrapModule` (DES-SETCMP-014). Inside the component, breadcrumbs use `$state.href(...)` and reselect/swap call `$state.go('settingsCompare', { id, left, right })` then reload themselves (dynamic params do not re-enter the state) — DES-SETCMP-013.

### Locale — ADR-003
- `SamNumberPipe` / `SamDatePipe` (`app-ng/core/`, `pure: false`) are line-for-line ports of the `samNumber` / `samDate` filters over `Intl.NumberFormat` / `Intl.DateTimeFormat`; each evaluation reads `SessionService.locale()` from the upgraded `SESSION_SERVICE` token, so a user switch re-renders without a reload. `LOCALE_ID` keeps Angular's default and is read by no code path; `DecimalPipe`/`DatePipe`/`registerLocaleData` are not used. Parity with the filters is asserted by `core/locale-parity.spec.ts` (en-GB, de-DE, fr-FR). UM-21's "via `LOCALE_ID`" wording is a follow-up (see below).

### Comparison logic — ADR-004
- `frontend/src/app-ng/settings/settings-compare.logic.ts` is the single comparison engine: no imports, no decorators; exports `EPSILON = 0.0005`, `toNumber`, `classify`, `rangeViolation`, `deltaPercent`, `severity`, `compare`, `visibleRows`, `defaultSelection`, `csvText`. The locale is a parameter. `SettingsCompareComponent` only loads data (history + two files through the upgraded `ApiClient`), holds view state and formats for display.
- **No server endpoint**: the client still fetches `GET /api/ieds/{iedId}/settings`, `GET /api/settings/{left|right}` and computes the comparison itself (Specify-gate decision OQ-1; CR-2031-F1 deferred — see follow-ups).
- The `text/csv` Blob/anchor download is `settings/csv-download.ts`, injected into the component through the `CSV_DOWNLOAD` token (`csv-download.token.ts`) so the spec can observe exports.

### Build and tooling — ADR-005
- Angular CLI workspace rooted at `frontend/` (`angular.json`, project `sam-ng`, `sourceRoot: src/app-ng`, builder `@angular-devkit/build-angular:browser`, `tsconfig*.json` with `strict` + `strictTemplates`). `ng build` (AOT, production default) writes `runtime.js`, `polyfills.js`, `main.js` with `outputHashing: none`, `vendorChunk: false`, `deleteOutputPath: true` into **git-ignored `frontend/src/ng/`**, which `server/dev-server.js` already serves as part of `src/`. A stub `src/app-ng/index.stub.html` satisfies the builder's `index` option and is never served.
- `package.json`: `build = ng build`, `build:dev`, `watch`, `prestart = npm run build` (so `npm start` always serves a fresh bundle — OQ-17), `start = node server/dev-server.js`, `test` = legacy Karma, `test:ng = ng test` (Angular Karma via `src/app-ng/karma.conf.js`), `lint = eslint src test`. One `npm install && npm run build` (UM-30).
- ESLint 8 + `eslint-plugin-angular` keeps linting `src/app` and `test`; `ignorePatterns` adds `src/ng/**`, `src/app-ng/**`, `.angular/**`. Angular code is type- and template-checked by `tsc --strict` / AOT.
- `frontend/Dockerfile` is two-stage (`node:20-alpine` build stage runs `npm ci` + `npm run build`; runtime stage `npm ci --omit=dev`, copies `server/` and the built `src/`); `frontend/.dockerignore` excludes `node_modules`, `src/ng`, `.angular`, `coverage`. `docker-compose.yml` unchanged.

### Shared services and events — ADR-006
- `app-ng/core/upgrade-providers.ts` upgrades the AngularJS singletons once via `InjectionToken`s `API_CLIENT`, `SESSION_SERVICE`, `EVENT_BUS`, `UI_ROUTER_STATE` (`useFactory: i => i.get('ApiClient' | 'SessionService' | 'EventBus' | '$state'), deps: ['$injector']`), registered only in `AppModule`. No `HttpClient`; every request still crosses `userHeaderInterceptor` / `apiErrorInterceptor`.
- `SamEventsService` (`userChanged$`, `settingsUploaded$` RxJS `Subject`s) is fed by the single `bridgeLegacyEvents()` call in `ngDoBootstrap`, which subscribes to `EventBus.EVENTS.USER_CHANGED` / `SETTINGS_UPLOADED`. No `$rootScope` in `src/app-ng/**`; `SAM_EVENTS` unchanged. The export toast still goes through the upgraded `EventBus.toast`.

### Legacy AngularJS code — `frontend/src/app/`
- `app.module.js`, `app.config.js`, `app.routes.js` — eight ui-router states (one now hosts a downgraded component).
- `core/` — `ApiClient` (all HTTP; interceptor adds `X-SAM-User`), `SessionService` (role/permissions/locale), `EventBus` (**`$rootScope.$broadcast` bus — legacy smell, now consumed from Angular only through the bridge**), `samDate/samNumber/samBytes/roleLabel/enumLabel` filters, `sticky-header` (**DOM-manipulating directive**, not used by the Angular table — CSS `position: sticky` on `table.grid.compare-grid thead th` instead, UM-22), `file-select`.
- `substations/ ieds/ scl/ records/ audit/ shell/` — **`$scope` controllers** + templates, unchanged. `settings/` no longer exists: `settings-compare.controller.js`, `settings-compare.html` and the temporary `settings-compare.logic-bridge.js` were retired in WI-SETCMP-05 (DES-SETCMP-021).
- `test/unit/` Karma/Jasmine — 4 spec files remain (api-client, event-bus, locale.filters, sticky-header; 9 cases); `test/e2e/` Protractor leftovers (not run).

- **FM-01 (controller business logic, ratchet)** — `tools/checks/baseline.json` lowered **12 → 2** in WI-SETCMP-03; the two remaining findings are `ied-detail.controller.js` and `substations.controller.js` (outside CR-2031). `settings-compare.component.ts` is scanned (it contains `@Component`) and matches no pattern; `*.logic.ts`, `csv-download.ts`, pipes and services are not scanned.

## Known exceptions / follow-ups
- **IC-20 display-only exception (OQ-1).** The UI computes range violations (`rangeViolation` in `settings-compare.logic.ts`) for display while the server validates ranges on upload (`SettingsService.validate()`); both compute, the server wins on upload, and only the client reports violations in already-ACTIVE files (e.g. the seeded `CEN01_SGT2_87T` v3). Accepted for this increment at the Specify gate; a server-side compare endpoint (CR-2031-F1, `GET /api/settings/compare?left&right`) is the follow-up, to be re-opened with the mobile-API decision (OQ-6).
- **UM-21 wording.** `standards/UI_MIGRATION_GUIDELINES.md` UM-21 says "via `LOCALE_ID` from the session"; the accepted design (ADR-003) reads `SessionService.locale()` at render time and leaves `LOCALE_ID` unused. The guideline text should be updated in a follow-up outside this feature branch.
- **Proposed `harness.yaml` addition (NOT applied).** The orchestrator's brief treated the compare screen as a two-reviewer path, but `review.two_reviewer_paths` lists only `backend/.../auth/**`, `audit/**`, `db/migration/**`. Proposal: add `frontend/src/app/settings/**` and `frontend/src/app-ng/settings/**`. Changing `harness.yaml` is outside the Document stage's outputs.
- **WORK_ITEMS wording drift.** WI-SETCMP-02 says `main.ts` does `import 'zone.js'` (DESIGN/ADR-001 govern: zone.js via CLI polyfills, never imported) and counted "18 app scripts" when day-zero `index.html` had 19 (ADR-001); after WI-05 removed the compare controller script it loads 18.
- **`docs/HYBRID_SPIKE_NOTES.md` cites "UM-09"** for the router rule; the guideline is UM-03 (OQ-11). Not edited here — not a Document-stage output.
- `tests/ui/specs/05-scl-import-and-audit.spec.ts` on `main` gained a wait (`4e96bff`) after this branch forked at `f701f90`; the branch does not carry it (PR #1 is mergeable without conflicts).
