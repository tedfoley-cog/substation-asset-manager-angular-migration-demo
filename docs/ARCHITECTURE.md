# Architecture (day zero)

## Runtime
```
browser ── :3000 frontend/server/dev-server.js (static + /api proxy) ── :8080 Spring Boot asset service ── H2 (dev/CI) | PostgreSQL 16 (compose)
```

## Backend — `backend/` (Spring Boot 3.3, Java 17)
- `web/` — `@RestController`s return DTOs only (ArchUnit-enforced; controllers may not touch repositories or return entities). `ApiExceptionHandler` produces the standard error envelope `{status, error, message, path, timestamp, details[]}`.
- `service/` — transactional use-cases: `SubstationService`, `IedService`, `SettingsService` (upload validation against min/max, version numbering, single ACTIVE), `SclImportService`, `RecordService` (COMTRADE download + audit), `AuditService` (append-only), `Permissions`.
- `scl/` — namespace-aware IEC 61850 SCL parser (`http://www.iec.ch/61850/2003/SCL`), XXE/DTD disabled, 5 MB limit, extension allow-list.
- `domain/` + `repository/` — JPA entities and Spring Data repositories; `@EntityGraph`s avoid N+1 on estate/detail reads.
- `db/migration/` — Flyway `V1__baseline_schema.sql`, `V2__reference_data.sql` (fictional multi-site transmission estate: substations, bays, IEDs, settings history, SCL imports, COMTRADE records, audit history).
- `auth/` — demo identity: `X-SAM-User` header → seeded user → `Role` (PROTECTION_ADMIN, ENGINEER, VIEWER, AUDITOR). Unknown/inactive → anonymous VIEWER.
- `api/openapi.yaml` is generated by `OpenApiExportTest` and committed; `OpenApiContractTest` fails on drift (IC-01).

## Frontend — `frontend/` (AngularJS 1.8.3, UI-Router 1.1)
- `app.module.js`, `app.routes.js` — eight ui-router states with dynamic query params.
- `core/` — `ApiClient` (all HTTP; interceptor adds `X-SAM-User`), `SessionService` (role/permissions), `EventBus` (**`$rootScope.$broadcast` bus — legacy smell**), `samDate/samNumber/samBytes/roleLabel/enumLabel` filters (de-DE / en-GB), `sticky-header` (**DOM-manipulating directive**), `file-select`.
- `substations/ ieds/ settings/ scl/ records/ audit/ shell/` — **`$scope` controllers** + templates. `settings-compare.controller.js` holds the comparison business logic (tolerance, de-DE parsing, range violations, severity ordering, CSV) — FM-01's main day-zero finding and the migration's main target.
- `test/unit/` Karma/Jasmine (14 specs); `test/e2e/` Protractor leftovers (not run).

## Migration target (what the harness is expected to produce)
Hybrid bootstrap via `@angular/upgrade/static` (`UpgradeModule`, `ngDoBootstrap`, remove `ng-app`), downgraded Angular components inside the AngularJS shell, comparison logic moved to a service (or the server, once Specify resolves the contradiction), `data-test` hooks unchanged, gauntlet green. See `standards/UI_MIGRATION_GUIDELINES.md` and `docs/HYBRID_SPIKE_NOTES.md`.
